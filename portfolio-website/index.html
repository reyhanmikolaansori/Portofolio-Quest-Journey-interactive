FundChainBlockchain Fundraising Platform

In progress

A team project: a fundraising platform for BINUS students that uses blockchain as a tamper-proof record. Every completed donation is hashed with Keccak-256 and the hash is stored in a smart contract. An integrity checker re-hashes the database records and compares them with the on-chain hashes; if anything was altered, the campaign is frozen and fund withdrawals are locked.

My role: Blockchain Integration Developer (relayer). I work on the relayer service that signs and submits donation hashes to the smart contract on Sepolia, so every verified donation gets a permanent on-chain record.

React · Vite · Tailwind · NestJS · Prisma · PostgreSQL (Supabase) · Solidity (Hardhat) · Sepolia · Vercel
