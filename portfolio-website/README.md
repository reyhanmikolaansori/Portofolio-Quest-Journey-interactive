# Reyhan Mikola Ansori – Portfolio

An RPG-inspired portfolio website. The landing screen works like a game HUD:
click anywhere to open the compass menu and explore my background, skills,
projects and contact details.

**Live site:** _add link after deploying_

## Built with
- HTML, CSS and vanilla JavaScript (no frameworks or build step)
- Canvas for the animated background
- SVG for the skill tree

## Project structure
```
index.html
css/style.css
js/skills.js        skill tree content
js/scene.js         background animation and compass
js/skill-tree.js    draws the skill tree
js/menu.js          menu and window navigation
assets/             photos, logos and icons
```

## Running locally
Open `index.html` with a local server (for example the Live Server extension in VS Code).
