# Portfolio Quest Journey

An RPG-inspired portfolio website. Click anywhere to open the compass menu and explore my background, skills, projects and contact details.

**Live site:** https://reyhan-mikola-ansori-portofolio-jou.vercel.app

## Built with

- HTML, CSS and JavaScript
- Canvas (animated background) and SVG (skill tree)
- Deployed on Vercel

## Run locally

Open the `portfolio-website` folder in VS Code and run `index.html` with the Live Server extension.
